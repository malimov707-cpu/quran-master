# AI Architecture

The implemented AI boundary uses replaceable provider contracts:

- Speech recognition
- Quran alignment
- Tajweed analysis
- AI explanation

## Safety rules

- AI output never substitutes for mentor judgment.
- Tajweed rules unavailable in the configured provider are not fabricated.
- Every review records confidence and model/provider metadata.
- Low-confidence results are routed to mentor review.
- Qur'an text is never generated by a language model.
- Providers run through background jobs with timeout and retry policy.
